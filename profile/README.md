## ◈ features

<table>
<tr>
<td width="50%">

**🛍️ Mod Store**
Browse and install mods directly from Modrinth. Filters lock results to your instance's version and mod loader — no incompatible installs.

**🔧 Multi Mod Loader**
Supports Vanilla, Fabric, Forge, and Quilt out of the box. Switch loaders per instance without touching config files.

</td>
<td width="50%">

**📦 Multi-Instance**
Run multiple Minecraft versions and configurations side by side. Each instance is fully isolated with its own mods, saves, and settings.

**⚡ Fast & Lightweight**
No Electron bloat. Feather is built to launch fast and stay out of your way.

</td>
</tr>
</table>

## ◈ getting started

**1. Download the installer**

Head to the [releases page](https://github.com/featherlauncher/feather/releases) and download the latest installer for your platform.

**2. Install and launch**

Run the installer. Feather will set itself up automatically.

**3. Create an instance**

Click **+** → choose your Minecraft version and mod loader → done.

**4. Browse mods**

Open the **Mod Store** tab, search for anything — mods are automatically filtered to match your instance.
